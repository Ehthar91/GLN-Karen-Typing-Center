GLN Karen Unicode Keyboard Privacy Policy

Last updated: September 4, 2026

Summary: GLN Karen Unicode Keyboard is designed to process keyboard input locally in your browser. It does not collect, store, sell, or transmit the text you type.

Information We Collect

GLN Karen Unicode Keyboard does not collect personally identifiable information, health information, financial information, authentication information, personal communications, location information, browsing history, user activity, or website content.

Keyboard Input

The extension processes keyboard input locally in the browser so that supported English keyboard keys can produce S'gaw Karen Unicode characters using the KarenKNU keyboard layout. The text you type is not sent to GLN or to an external server by the extension.

Local Settings

The extension uses Chrome storage only to remember extension settings, such as whether Karen input is turned on or off. These settings are used to provide the extension's functionality and are not sold or used for advertising.

Data Sharing

GLN Karen Unicode Keyboard does not sell or transfer user data to third parties. It does not use user data for advertising, creditworthiness, lending, or purposes unrelated to providing Karen Unicode keyboard input.

Website Access

The extension requires access to webpages so it can provide Karen Unicode input in editable fields on supported websites. This access is used only to provide the keyboard functionality.

Changes to This Policy

If the extension's privacy practices change, this policy will be updated to describe those changes.

Contact

For questions about this privacy policy or GLN Karen Unicode Keyboard, visit the GLN Karen Typing Center.
