BUS CALL - FIREBASE NOTE (v1.1)
================================

Bus Call now reuses the same authenticated Realtime Database namespace already used by Classroom Quiz.
Its internal Firebase room key is prefixed with BUS_, so a visible room code such as GLN25 is stored separately from normal quiz rooms.

NO NEW BUS-CALL DATABASE RULE IS REQUIRED.

If Classroom Quiz / Car Race already connects on your website, Bus Call should connect using the same anonymous Firebase session. Staff do not need to sign in to a Google or staff account.

If Bus Call still says it cannot connect:
1. Test whether Classroom Quiz can create a live room.
2. In Firebase Console > Authentication > Sign-in method, make sure Anonymous authentication is enabled.
3. Make sure firebase-config.js still points to the gln-karen-typing-center Firebase project.

The firebase-rules.json file can still contain the older busCallRooms rule; Bus Call v1.1 does not depend on that path.
