BUS CALL - ONE-TIME FIREBASE RULES UPDATE
=========================================

The Bus Call feature uses the same Firebase Realtime Database and anonymous sign-in already used by Classroom Race/Quiz.
Teachers and the bus caller do NOT need to connect a Google account.

IMPORTANT: GitHub Pages cannot deploy Firebase Realtime Database rules.
After uploading this website build, update your Firebase Realtime Database rules once.

Option A - Firebase Console
1. Open Firebase Console for project: gln-karen-typing-center
2. Open Realtime Database > Rules.
3. Replace the rules with the contents of firebase-rules.json from this ZIP.
4. Click Publish.

The new rules add the /busCallRooms path. Without that rules update, Bus Call will show a permission error.

How staff use it
----------------
1. Bus caller: Classroom Tools > Bus Call > Start Caller Mode.
2. Share the displayed room code with classroom teachers.
3. Teachers: Classroom Tools > Bus Call > enter the same code > Join Bus Calls.
4. Caller enters a bus number and presses Call Bus.
5. The bus number immediately appears as a large popup on every connected classroom screen.

Room codes are the access key. Use a school-specific code that is not easy for students to guess, or use the generated random code.
