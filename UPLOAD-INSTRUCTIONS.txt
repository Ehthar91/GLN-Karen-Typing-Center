GLN Classroom Tools — Flashcards Custom Google Classroom Share Title

Upload the 4 files in this folder directly to the ROOT of your GitHub repository and replace the existing files:

- index.html
- flashcards.html
- flashcards-app.js
- flashcards-styles.css

What changed
- Each Flashcards class now has a Google Classroom Share Title field.
- Type exactly how you want the class to appear in Google Classroom.
- The Google Classroom share button updates to use the typed title.
- Click Save Title to remember the custom title for that class in Firebase/Firestore.
- Click Use Class Name to return to the automatic "Class Name — Flashcards" title.
- The custom share title does NOT rename the Flashcards class or its decks.

No Firebase rules update is required.

After GitHub Pages redeploys, hard-refresh the website before testing.
