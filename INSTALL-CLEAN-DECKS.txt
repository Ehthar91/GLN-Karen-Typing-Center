GLN Karen Typing Center — Flashcards Clean Deck Overview

WHAT CHANGED
- Removed the old "Select all / Study Selected / Clear" controls from the deck list toolbar.
- Removed the old deck-card selection checkboxes and decorative teal checkmarks.
- Class-level STUDY and QUIZ still open the dedicated Choose Decks popup.
- The popup still supports individual selection, Select All, and Clear Selection.
- Preserves per-deck Study/Quiz, drag-and-drop deck reordering, mastery tracking,
  Unicode Type Answer keyboard, comma-separated definition grading, creator badge.
- Previous choices are remembered within the current class (until you switch classes).

GITHUB INSTALLATION — PATCH ONLY
1. Unzip this patch.
2. Upload ONLY these three files to the repository ROOT:
     flashcards.html
     flashcards-app.js
     flashcards-styles.css
3. Replace the old root files, then commit changes.
4. Do not delete or modify type/index.html, quiz.js, or Firebase files.
5. After GitHub Pages deploys, reload Flashcards (hard refresh if necessary).
6. Open a class. Study and Quiz at the top should open Choose Decks;
   the older selection strip and card checkmarks should be gone.

This package is based on the most recent Flashcards "Select Decks" release
and retains the Quiz Unicode keyboard and one-definition answer grading.
