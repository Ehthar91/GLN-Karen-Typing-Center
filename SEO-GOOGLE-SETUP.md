# Google Search setup for GLN Karen Typing Center

The site now includes search-engine metadata, a canonical URL, Open Graph tags, structured data, `robots.txt`, and `sitemap.xml`.

## After uploading this ZIP to GitHub

1. Make sure GitHub Pages has finished deploying.
2. Open Google Search Console: https://search.google.com/search-console/
3. Add a **URL prefix** property for:
   `https://ehthar91.github.io/GLN-Karen-Typing-Center/`
4. Use **URL Inspection** and inspect the home page URL.
5. Click **Request indexing**.
6. Open **Sitemaps** and submit:
   `sitemap.xml`

Google decides when and how pages appear in search results, so indexing is not guaranteed or immediate.
