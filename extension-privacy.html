GLN Sgaw Karen Unicode Keyboard — Privacy Policy

Effective date: October 22, 2026

GLN Sgaw Karen Unicode Keyboard is a browser extension that helps users type Sgaw Karen Unicode characters in supported web text fields, and provides an on-device Unicode typing pad for copying text into applications such as Google Docs.

Information processed

When you turn on the keyboard for a website, the extension processes keyboard events and text insertion locally in your browser to convert physical keys to Sgaw Karen Unicode. The extension runs on standard HTTP and HTTPS web pages to enable this feature, but only performs the key-to-character conversion in editable fields on websites you enable. It does not intentionally operate in password inputs.

The extension reads the active tab's website address in its popup to show which site you are enabling. It saves only your enabled website origins (for example, https://example.com) in Chrome's local extension storage so your on/off preferences persist. Text entered in the popup typing pad stays in the pad temporarily until you copy or clear it, or the popup closes.

Collection, sharing, and transmission

The extension does not send your keystrokes, typed text, website content, browsing history, or saved website preferences to GLN, to analytics services, or to other third parties. It does not require a user account. It has no built-in analytics, advertising, or remote server requests.

Permissions

Website access: The keyboard script is available on HTTP and HTTPS pages so users can type in supported editable fields after choosing to enable the site. Storage: Remembers on/off settings by website on your device. Active tab: Identifies the website in the popup so you can control the keyboard for that site.

Your choices

You can switch the keyboard off for any site in the extension popup. You can remove its locally saved settings by removing the extension or clearing its extension storage. The popup has a Clear button for its current typing pad. Uninstalling the extension stops it from processing keyboard events.

External websites

Websites where you type may independently process or store the text you enter, according to their own privacy policies. This extension does not control those sites' data practices.

Changes and contact

We may update this policy if the extension's behavior changes. Any changes will be reflected by updating this page and its effective date. For more information about GLN Karen Typing Center, visit glnkarentypingcenter.com.
