# GLN Karen Typing Center

An online S'gaw Karen Unicode keyboard, typing practice center, typing games, and classroom car race.

## Included features

- Karen Unicode keyboard with physical and on-screen keys
- Guided typing lessons with highlighting, WPM, and accuracy
- Word Sprint and Falling Words games
- Classroom Car Race with one shared room code and student names

## Build

Run `npm run build`. The deployable Worker is generated in `dist/`.

## GitHub note

You can upload this source to a GitHub repository. GitHub Pages can display the static typing tools, but the live multiplayer race requires a server with a Cloudflare D1-compatible database. The included Sites configuration, Worker, schema, and migration provide that backend when deployed through ChatGPT Sites.
